# Public Layer interface is enforced, not conventional

SemVer and the Identity port only hold if the Host cannot reach around them. Playground and future Products may import only a Nuxt Layer’s documented public entrypoints; deep imports of another Layer’s Tiers fail CI (ESLint). Tiers may import freely inside their own Layer. A documented convention without a fence is how Drizzle tables leak into the Playground; waiting until 1.0 lets that leak become the real interface.
