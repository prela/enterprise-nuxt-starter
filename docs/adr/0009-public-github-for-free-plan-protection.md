# Public GitHub so Free-plan branch protection can enforce

`enterprise-nuxt-starter` stays a **public** GitHub repository so GitHub Free can enforce pull requests (and no direct push) on `develop` and `main`. Private + enforced protection needs GitHub Pro or an org on Team/Enterprise; we chose public over unpaid, unenforced GitFlow. ADR-0004 still means owner-plus-agents, not “the source must be a private repo.”
