# Playground proves catalogue Layers; the docs site is a future Product

Phase 7 does not publish Layers and does not add a Product to this repository. The Playground Host extends every shipped Layer and carries a thin `docs` proof collection so `extends` composition is real. The marketing/docs site (guides for users and agents) is a separate Product later. Putting that encyclopedia in the Playground would make the Host a Product and contradict ADR-0001. Publishing now and depending from a production docs Product would be the 1.0.0 trigger (ADR-0005).
